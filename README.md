### 🎯 Challenge Objective

Understand the different applications of SQL subqueries and identify which operation is not considered a valid use case in the given question.

### ❓ Question

Which of the following is NOT a valid use case for subqueries?

**Options:**

1. Filtering rows based on aggregate functions.
2. Retrieving data from multiple tables.
3. Inserting data into a table.
4. Updating data in a table.

### ✅ Correct Answer

**Inserting data into a table.**

### 💡 Explanation

Subqueries are SQL queries written inside another SQL statement. They help retrieve, filter, compare, and process data using the results of another query.

Common applications include:

- Filtering rows based on aggregate functions.
- Retrieving related information from multiple tables.
- Using query results in conditional operations.
- Updating records based on values returned by another query.

In the given challenge, inserting data into a table is identified as the option that is NOT a valid use case for subqueries.

## 🆕 Day 99 – Maximum Nesting of Subqueries

### 📌 Challenge Information

- 📅 **Day:** 99
- 🧩 **Challenge:** Maximum Nesting of Subqueries
- 💻 **Platform:** SQL Challenge
- 🗄️ **Language:** SQL
- 🔍 **Topic:** SQL Subqueries
- 📋 **Concept:** Nested Subqueries
- 📸 **Submission Screenshot:** Screenshot 2026-11-02 202539.png
- 📁 **Directory:** Day99-SQL
- ✅ **Status:** Completed

### 🎯 Challenge Objective

Understand nested subqueries and identify whether SQL has a specific fixed limit on the number of subqueries that can be nested within a single SQL statement.

### ❓ Question

What is the maximum number of subqueries that can be nested in a single SQL statement?

### ✅ Correct Answer

**There is no specific limit.**

### 💡 Explanation

Nested subqueries are SQL queries placed inside another SQL query.

They allow one query to use the results of another query for filtering, comparison, and data retrieval.

There is no universal fixed maximum number of nested subqueries applicable to every SQL database system. Actual nesting limits may depend on the database engine, SQL dialect, and system implementation.

### 💻 Example SQL Query

    SELECT employee_name, salary
    FROM employees
    WHERE department_id IN (
        SELECT department_id
        FROM departments
        WHERE location_id IN (
            SELECT location_id
            FROM locations
            WHERE city = 'Pune'
        )
    );

### 🔍 Query Explanation

1. The innermost query retrieves the location ID for Pune.
2. The middle query retrieves department IDs associated with that location.
3. The outer query retrieves employees belonging to those departments.
4. Multiple subqueries work together to retrieve the required records.

### 🧠 Key Learnings

- 🔹 Understood the concept of nested SQL subqueries.
- 🔹 Learned how multiple subqueries work within a single SQL statement.
- 🔹 Explored the relationship between inner and outer queries.
- 🔹 Improved understanding of nested query structures.
- 🔹 Learned how subqueries support complex data retrieval.

### 🎓 Learning Outcome

Strengthened my understanding of nested SQL queries and learned how multiple subqueries can be combined to retrieve data through different levels of conditions.

**Key Takeaway:** SQL supports nested subqueries, but the actual maximum nesting depth depends on the database system.

## 🆕 Day 98 – Reference Columns from Outer Query

### 📌 Challenge Information

- 📅 **Day:** 98

- 💻 **Platform:** SQL Challenge
- 🗄️ **Language:** SQL
- 🔍 **Topic:** SQL Subqueries
- 📋 **Concept:** Correlated Subquery
- 📸 **Submission Screenshot:** Screenshot 2026-11-01 071813.png
- 📁 **Directory:** Day98-SQL
- ✅ **Status:** Completed

### ❓ Question

Which type of subquery can reference columns from the outer query?

### ✅ Correct Answer

**Correlated Subquery**

### 💡 Explanation

A correlated subquery is a subquery that refers to one or more columns from the outer query.

Unlike an independent subquery, a correlated subquery depends on values supplied by the outer query.

### 💻 Example SQL Query

    SELECT e1.employee_id, e1.name, e1.salary
    FROM employees e1
    WHERE e1.salary > (
        SELECT AVG(e2.salary)
        FROM employees e2
        WHERE e2.department_id = e1.department_id
    );

### 🎓 Learning Outcome

Strengthened my understanding of correlated subqueries and how inner queries can access values from outer queries to perform dynamic comparisons.

**Key Takeaway:** A correlated subquery references columns from the outer query and depends on its values.

## 🆕 Day 97 – Matching Subquery Result with a Column

### 📌 Challenge Information

- 📅 **Day:** 97
- 🧩 **Challenge:** Matching Subquery Result with a Column
- 💻 **Platform:** SQL Challenge
- 🗄️ **Language:** SQL
- 🔍 **Topic:** SQL Subqueries
- 📋 **Concept:** IN Operator
- 📊 **Difficulty:** 750
- 📸 **Submission Screenshot:** Screenshot 2026-10-31 155416.png
- 📁 **Directory:** Day97-SQL
- ✅ **Status:** Completed

### ❓ Question

Which keyword is used to compare a subquery result with a column value in the outer query?

### ✅ Correct Answer

**IN Operator**

### 💡 Explanation

The IN operator checks whether a value matches any value in a list or in the result returned by a subquery.

- IN compares a value with a list of values.
- A subquery can provide the list used by IN.
- The outer query returns rows that satisfy the membership condition.
- BETWEEN checks whether a value falls within a range.
- EXISTS checks whether a subquery returns at least one row.
- LIKE is used for pattern matching in text.

### 💻 Example SQL Query

    SELECT *
    FROM employees
    WHERE department_id IN (
        SELECT department_id
        FROM departments
        WHERE location = 'Pune'
    );

### 🎓 Learning Outcome

Strengthened my understanding of using the IN operator with subqueries to match column values against a dynamically generated result set.

**Key Takeaway:** Use IN when a column value in the outer query needs to match any value returned by a subquery.

- 📅 **Day:** 96
- 🧩 **Challenge:** Sub-query Which Executes Only Once
- 💻 **Platform:** SQL Challenge
- 🗄️ **Language:** SQL
- 🔍 **Topic:** SQL Subqueries
- 📋 **Concept:** Scalar Subquery
- 📊 **Difficulty:** 750
- 📸 **Submission Screenshot:** Screenshot 2026-10-30 093721.png
- 📁 **Directory:** Day96-SQL
- ✅ **Status:** Completed

### ❓ Question

Which type of subquery is executed once for the entire outer query?

### ✅ Correct Answer

**Scalar Subquery**

### 💡 Explanation

A scalar subquery returns a single value consisting of one row and one column.

An uncorrelated scalar subquery does not depend on the outer query. Its result can be evaluated once and reused by the outer query.

### 💻 Example SQL Query

    SELECT name, salary
    FROM employees
    WHERE salary > (
        SELECT AVG(salary)
        FROM employees
    );

### 🎓 Learning Outcome

Strengthened my understanding of scalar subqueries, their execution behavior, and the differences between various SQL subquery types.

**Key Takeaway:** An uncorrelated scalar subquery can calculate a single value for use by the outer query.

### 📚 What Is a Subquery?

A subquery is a SQL query nested inside another SQL statement. The inner query supplies a result that the outer query can use to filter records, compare values, retrieve information, or perform calculations.

### 💻 Example SQL Query

    SELECT name, salary
    FROM employees
    WHERE salary > (
        SELECT AVG(salary)
        FROM employees
    );
